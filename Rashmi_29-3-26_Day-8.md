# Reverse Linked List (Java)

## Description
Reverses a singly linked list by creating a new list in reverse order.

## Approach
- Traverse the original list
- Create new nodes and link them in reverse using `prev`
- Return the new head

## Complexity
- Time: O(n)
- Space: O(n)
